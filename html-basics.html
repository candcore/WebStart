01

Что такое HTML?

HTML — HyperText Markup Language, язык гипертекстовой разметки. Он не выполняет вычисления: его задача — организовать информацию на странице.

СтруктураРазделяет страницу на логические части
СодержаниеХранит текст, ссылки и изображения
СемантикаОбъясняет назначение элементов
Запомни

HTML — это каркас дома. CSS добавит цвет, размеры и расположение элементов.

02

Структура документа

У каждой HTML-страницы есть базовый каркас. Создай файл index.html и добавь:

index.html
<!doctype html>
<html lang="ru">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Моя страница</title>
  </head>
  <body>
    <h1>Привет, мир!</h1>
  </body>
</html>
<!doctype html>

Сообщает браузеру, что используется современный HTML5.

<head>

Содержит служебную информацию, название и подключения.

<body>

Содержит всё, что пользователь видит на странице.

04

Семантическая разметка

Семантические теги называют роль блока. Это делает код понятнее, улучшает доступность и помогает поисковым системам.

<header> Шапка сайта
<nav> Навигация
<main>
<section> Раздел
<article> Статья
<footer> Подвал
