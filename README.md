# WebStart — основы HTML и CSS

Интерактивный русскоязычный мини-курс для начинающих веб-разработчиков. Проект объединяет короткую теорию, примеры кода, практическое задание и тест с мгновенной обратной связью.

## Демо

После публикации сайт доступен по адресу: **https://candcore.github.io/WebStart/**

## Возможности

- отдельные уроки по HTML и CSS;
- подсвеченные примеры кода и кнопки копирования;
- практический проект «Персональная веб-визитка»;
- чек-лист с сохранением прогресса в `localStorage`;
- интерактивный тест из 10 вопросов с объяснениями;
- адаптивная навигация и дизайн для мобильных устройств;
- поддержка клавиатурной навигации и `prefers-reduced-motion`;
- автоматический деплой на GitHub Pages.

## Структура

```text
WebStart/
├── index.html          # Главная страница
├── html-basics.html    # Урок по HTML
├── css-basics.html     # Урок по CSS
├── practice.html       # Практическое задание
├── quiz.html           # Интерактивный тест
├── 404.html            # Страница ошибки
├── styles.css          # Общие стили
├── script.js           # Навигация, прогресс и тест
└── .github/workflows/pages.yml
```

## Локальный запуск

Сайт не требует сборки или установки зависимостей.

1. Скачайте репозиторий.
2. Откройте `index.html` в браузере.

Для локального HTTP-сервера:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.
