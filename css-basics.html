03

Блочная модель

Браузер представляет каждый элемент как прямоугольную коробку из четырёх слоёв.

margin · внешний отступ
border · рамка
padding · внутренний отступ
content
содержимое
margin: 24px;

Создаёт пространство снаружи элемента.

padding: 24px;

Создаёт пространство между рамкой и содержимым.

border: 1px solid;

Добавляет видимую границу элемента.

04

Flexbox и адаптивность

Flexbox помогает выстраивать элементы в ряд или колонку и управлять расстоянием между ними.

styles.css
.cards {
  display: flex;
  gap: 24px;
  justify-content: center;
  flex-wrap: wrap;
}

@media (max-width: 700px) {
  .cards { flex-direction: column; }
}
